# Sales

The path from stranger to booked call.

Each folder in here is an agent team. Each team has a `team.md` (its members and its workflows) and one folder per team member. Add a new team the way AGENTS.md says, then run the sync command (`python3 tools/sync.py`, or `py tools/sync.py` on Windows).
