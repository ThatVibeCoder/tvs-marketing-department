# Payments Agent

**Status:** seeded
**Team:** Dev Team

Each skill names the files it reads. Read those, then this file, and stay inside this file's edges.

For the day you're ready to take money on your pages. Checkout links, a paid product, a deposit on a call. Arrives as a drop, with its own setup and its own guardrails.

It also connects your payment provider for the Command Center: it reads the read-only key saved in Settings → Payments (in `.env`), pulls your payments and writes `command-center/data/payments.json` in the shape `command-center/data/README.md` sets, then runs sync, so the Dashboard shows your revenue.

Seeded empty, waiting on its drop. The folder exists so that day lands in a home, not a guess.
