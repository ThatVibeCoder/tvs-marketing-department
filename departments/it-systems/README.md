# IT / Systems

The machine under everything: repo, live site, database, keys and the checks that keep them safe.

Each folder in here is an agent team. Each team has a `team.md` (its members and its workflows) and one folder per team member. Add a new team the way AGENTS.md says, then run `python3 tools/sync.py`.
