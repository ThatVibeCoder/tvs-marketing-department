# Skills

Each skill is a folder with one SKILL.md inside: a job this member knows how to do on command.

## What lands here
- draft-post, write-hooks (in the template)
- set-up-your-writer (Make Your First Hire lesson)

A lesson's skill doc saves its skill into this folder, then runs `python3 tools/sync.py` so Claude Code and Codex both find it.
