# Skills

Each skill is a folder here with one `SKILL.md`. These land here as you go through the classroom:

- lock-your-icp (Lock In Your ICP lesson)
- find-your-contrarian-take (Contrarian Take lesson)
- solve-friction-points (Solve 5 Friction Points lesson)
- build-your-offer (Build Your Offer lesson)
- write-to-your-personas (Write To Your Buyer Personas lesson)

A lesson's skill doc saves its skill into this folder, then runs `python3 tools/sync.py` so Claude Code and Codex both find it.
