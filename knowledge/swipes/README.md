# Swipes

**Filled by:** the Researcher's collect-swipes skill, whenever you send something that caught your eye.

One file per swipe: `<YYYY-MM-DD>-<short-name>.md`, four lines each: what it is, why it works, the shape worth stealing, and its job (hook, offer, proof or structure). The job tag is how a writer finds "I need a proof section" later.
