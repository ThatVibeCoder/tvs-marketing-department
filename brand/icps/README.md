# More ICPs

**Filled by:** the lock-your-icp skill (Lock In Your ICP lesson), once for each extra buyer group.

`brand/icp.md` is your main ICP: every writer, page and offer reads it first. When you sell to more than one kind of buyer, each extra one gets its own file here, `<short-name>.md`, in exactly the same shape (copy `_template.md`). A job only uses an extra ICP when you name it ("write this for the agency owners ICP").
