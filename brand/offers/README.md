# More Offers

**Filled by:** the build-your-offer skill (Build Your Offer lesson), once for each extra offer, or the offer builder in the Command Center (My Business → Offers).

`brand/offer.md` is your main offer: the landing page and every skill read it. Anything else you sell gets its own file here, `<short-name>.md`, in exactly the same shape (copy `_template.md`). A job only uses an extra offer when you name it.
