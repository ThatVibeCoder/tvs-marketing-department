# Guidelines

This grows as you make calls. Every time you correct your AI on something, tell it to log the rule here. That's how this file gets built, one real correction at a time, not written up front.

## Banned Words
Words and phrases that never appear in anything written for this brand, and why.

## Formatting Rules
How things get structured on the page: headers, lists, line breaks, anything you've corrected more than once.

## Things This Brand Never Does
Calls that aren't about words, tactics, channels, or moves you've ruled out for this brand specifically.

## Updates
Every change to this file gets one dated line here, newest on top: what changed and why (for example `2026-11-02: added the price, owner confirmed`). This is how the file keeps itself current instead of going stale.
