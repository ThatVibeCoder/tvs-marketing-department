# Briefs

The company strategist saves every brief for the next team member here, one file each: `<YYYY-MM-DD>-<team-member>.md` (for example `2026-11-02-reply-agent.md`). The newest file is the current pick.

Every brief has the same four parts:

## Team member
The folder it wakes, for example `departments/marketing/follow-up-team/reply-agent/`.

## The job
What it does, in plain words, and which finding in `knowledge/business-audit.md` it answers.

## Done looks like
What the owner will see when it's working.

## Leave alone
What this team member must not touch.
