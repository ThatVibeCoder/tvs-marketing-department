# Skills

Each skill is a folder here with one `SKILL.md`. These land here as you go through the classroom:

- brain-dump-your-business (in the template)
- company-brain-dump (in the template)
- walk-your-business (Walk Your Whole Business lesson)
- cut-what-you-dont-need (Cut What You Don't Need lesson)
- company-strategist (in the template): the front door, it routes every ask to the team that owns it
- set-up-your-company-strategist (in the template; the Set Up Your Company Strategist lesson runs it)
- speed-run-your-team (Speed Run a Team Member lesson; not built yet, so until then a team member gets set up the way AGENTS.md says under "Setting up a seeded team member")

A lesson's skill doc saves its skill into this folder, then runs the sync command (`python3 tools/sync.py`, or `py tools/sync.py` on Windows) so Claude Code and Codex both find it.
