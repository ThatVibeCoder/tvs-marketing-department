# Skills

Skills this team member knows live here, one folder per skill. A skill is clean steps, shareable; what the owner prefers stays in the team member's Memory.


## What lands here
- plan-the-week, post-content, read-the-stats, content-brain, stand-up-a-specialist (in the template)
- set-your-content-mix (The Everyone Trap lesson)

A lesson's skill doc saves its skill into this folder, then runs the sync command (`python3 tools/sync.py`, or `py tools/sync.py` on Windows) so Claude Code and Codex both find it.
