# edit-a-draft

## Read first
`brand/voice.md` (the single source of truth for how the owner sounds), `brand/guidelines.md`, and the draft.

## Steps
1. Read the draft out loud in the owner's voice. Mark every stumble.
2. Check it against every section of `brand/voice.md`, especially Words I Never Use and Never Sound Like This. Name each miss with the rule it broke.
3. Fix the misses, cut anything a stranger would skip, and keep the owner's own phrases.
4. Show the owner the edited draft with a one-line note per real change.

## Rules
- Never copy voice rules into this file or the draft's folder. Point at `brand/voice.md`.
- A miss that happens twice is a gap in `brand/voice.md`. Offer to add the rule there, and add it only once the owner confirms, marked (owner confirmed).
