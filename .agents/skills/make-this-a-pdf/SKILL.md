# make-this-a-pdf

This is the designer's report-styling skill. It wraps an existing report in the owner's brand (colors, typography) as one self-contained HTML file the owner can open and print to PDF, then offers to save it to Drive or note it in Notion.

Read `departments/marketing/content-team/designer/skills/make-a-report-doc/SKILL.md` in full and follow it exactly. Do not improvise the choreography here; that file owns it.

It never restyles the findings themselves, only dresses what's already there.
