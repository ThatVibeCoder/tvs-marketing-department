# audit-my-site

This is the website team's inward-looking summon, the sibling of the marketing checkup. It runs once the landing page is live, then quarterly: page builder reviews every live page, the traffic agent checks SEO, AI visibility, and speed, and the security checker sweeps the form path.

Read `departments/marketing/website-team/team.md` in full and follow its "Summon: audit my site" section exactly, in the order it lists. Do not improvise the choreography here; that file owns it.

The compiled report lands at `knowledge/SITE-AUDIT-<month>.md`, triaged Quick win / Strategic / Long-term with an owner named for each finding, ending in the one fix to do first. If the owner wants it shareable, offer `make-this-a-pdf`.
